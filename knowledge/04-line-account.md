# การเชื่อมบัญชี LINE

เข้าสู่ระบบด้วย LINE ก่อนสมัคร ใบสมัครจะอยู่ในบัญชี LINE ของคุณทันที
หากสมัครไว้ก่อนแล้ว ให้เข้าสู่ระบบด้วย LINE ที่หน้าติดตามสถานะ แล้วเลือกเพิ่มใบสมัครที่สมัครไว้ก่อนหน้า โดยยืนยันด้วยเลขที่ใบสมัคร เลขประจำตัวประชาชน และหมายเลขมือถือ
ระบบจะผูก LINE กับข้อมูลบุคคลหลังเจ้าหน้าที่ตรวจเอกสารผ่านแล้วเท่านั้น

## ยกเลิกการเชื่อมบัญชี LINE
กดชื่อบัญชีที่มุมขวาบนของเว็บไซต์ แล้วเลือกยกเลิกเชื่อมบัญชี LINE
