# ไฟล์ตั้งต้นของคลังความรู้ AI

ไฟล์ `.md` ที่มี `หมวด:` บรรทัดแรกจะถูกนำเข้าด้วย `npm run knowledge:import` เป็น **ฉบับร่าง**
เจ้าหน้าที่ต้องตรวจและกดเผยแพร่ที่ Admin > คลังความรู้ AI ก่อน AI จึงจะใช้ตอบ

เนื้อหาเขียนจากการทำงานจริงของระบบเท่านั้น ไม่มีวัน ราคา หรือระเบียบที่ยังไม่ได้รับจากผู้ว่าจ้าง
ตารางอบรม ที่นั่ง ช่องทางติดต่อ และวิธีชำระเงิน AI อ่านจากฐานข้อมูลสดอยู่แล้ว **ไม่ต้องใส่ในไฟล์**

ข้อมูลที่ต้องขอเพิ่ม: คุณสมบัติผู้เข้าอบรม, เนื้อหา/ชั่วโมงหลักสูตร, เกณฑ์การผ่าน, อายุใบประกาศ, การคืนเงิน/เลื่อนรุ่น, ระเบียบการแต่งกาย, การเดินทาง/ที่พัก
