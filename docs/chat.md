# รวมแชต LINE OA

## AI หยุดและเริ่มเมื่อไร
| เหตุการณ์ | ผล |
|---|---|
| ปิดสวิตช์ใหญ่ | ไม่ตอบทุกแชต |
| ปิดสวิตช์ในแชต / เจ้าหน้าที่ตอบเอง / ลูกค้าขอคุยกับเจ้าหน้าที่ | หยุดเฉพาะแชตนั้น |
| เปิดสวิตช์ในแชต หรือกด "ปิดเคส" | AI กลับมาดูแล |
| เจ้าหน้าที่ตอบหรือปิด AI ขณะ AI กำลังคิด | คำตอบ AI ถูกทิ้ง |
| ไม่มีข้อมูล, MiniMax ขัดข้อง, ถามเกิน 20 ครั้ง/ชม., ข้อความเข้าช้าเกิน 2 นาที, ส่งรูป/ไฟล์ | ขึ้นกลุ่ม "ต้องการคน" |

## การส่งและโควตา
ใช้ reply token ก่อน (ไม่กินโควตา) ถ้าหมดอายุจึง push หลังตรวจโควตา ข้อความที่ใช้โควตามีคำว่า `push`
ถ้า reply ไม่รู้ผล ระบบไม่ส่งซ้ำเอง เพราะลูกค้าอาจได้สองข้อความ ให้ตรวจใน LINE ก่อนกด "ส่งอีกครั้ง" ส่วน push ใช้ retry key จึงส่งซ้ำได้โดยไม่ซ้ำข้อความ

## ข้อจำกัด
- แสดงเฉพาะข้อความที่เข้ามาหลังเปิด webhook ประวัติเก่าใน OA Manager ดึงไม่ได้
- ข้อความที่ตอบจาก LINE OA Manager จะไม่แสดงที่นี่ และ AI ไม่รู้ว่ามีคนตอบแล้ว ให้ตอบจากหน้านี้ที่เดียว
- ส่งได้เฉพาะข้อความ ไม่รับแชตกลุ่ม เปิดดูได้เฉพาะรูป JPG/PNG และ PDF ไม่เกิน 10 MB
- หน้าแชตถามข้อมูลใหม่ทุก 3 วินาที (shared hosting ไม่เหมาะกับการเชื่อมต่อค้าง)
- AI ตอบทีละคำถาม ไม่จำบทสนทนาก่อนหน้า เพื่อไม่ส่งประวัติแชตออกนอกระบบ

ลองบนเครื่อง: `npm run dev:local` แล้วเปิด http://localhost:3001/simulate เพื่อพิมพ์เป็นลูกค้า
