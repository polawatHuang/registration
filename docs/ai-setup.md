# AI (MiniMax) และคลังความรู้

1. Admin > ตั้งค่า > MiniMax: ใส่ API key, ภูมิภาคให้ตรงกับ key (สากล/จีน) และชื่อ model แล้วกดทดสอบ
2. `npm run knowledge:import` นำไฟล์ใน `knowledge/` เข้าเป็นฉบับร่าง
3. Admin > คลัง AI: อัปโหลดไฟล์หรือเพิ่มถาม-ตอบ → **ตรวจข้อความ** → เผยแพร่ → ทดสอบถาม

## เลือก model (ราคาทางการ พ.ย. 2569, USD ต่อ 1 ล้าน token)
| Model | เข้า | ออก | ระบบเรียกอย่างไร |
|---|---|---|---|
| **MiniMax-M3.1-Flash** (แนะนำ) | 0.15 | 0.60 | คิดเสมอ ระบบตั้งระดับต่ำ ปรับได้ที่ คลัง AI > ตั้งค่า AI |
| MiniMax-M3 | 0.30 | 1.20 | ระบบปิดการคิด |

ทั้งสองรุ่นไม่ใช้ Temperature และนับ token การคิดรวมใน Max tokens (แนะนำ 4000) ใส่ราคาที่ตั้งค่า AI เพื่อดูค่าใช้จ่าย ตรวจราคาล่าสุดที่ https://platform.minimax.io/docs/guides/pricing-paygo
ถ้า MiniMax ไม่รับพารามิเตอร์เฉพาะรุ่น (400) ระบบลองแบบพื้นฐานอีกครั้งเดียว

## เครดิตหมดต้องทำอย่างไร
1. เปิด Admin > คลัง AI > **เครดิต AI** ดูสาเหตุและขั้นตอน
2. เติมที่ https://platform.minimax.io/user-center/payment/balance
3. กด **ตรวจอีกครั้ง** (หรือรอระบบลองเองภายใน 10 นาที) แล้วกด **บันทึกยอด**

## ติดตามเครดิตและค่าใช้จ่ายเป็นเงินบาท
MiniMax ไม่มี API ให้ดูยอดเงิน จึงต้องกรอกยอดเอง
1. เปิดหน้ายอดเงินของ MiniMax ดูยอดคงเหลือ (Balance)
2. ที่ **เครดิต AI > อัปเดตยอดจาก MiniMax** พิมพ์ตัวเลข (US$) แล้วกด **บันทึกยอด** ระบบจะบอกว่ายอดที่ประมาณไว้ต่างจากของจริงเท่าไร ควรทำสัปดาห์ละครั้งหรือหลังเติมเงิน
3. ยอดทั้งหน้าแสดงเป็นบาท ระบบดึงอัตรา USD→THB อัตโนมัติทุก 12 ชั่วโมงจากอัตราอ้างอิง ECB (Frankfurter, สำรองด้วย ExchangeRate-API) ไม่ต้องใช้ key และไม่ส่งข้อมูลของระบบออกไป ดึงไม่ได้จะใช้อัตราเดิม ถ้าต้องการให้ตรงกับที่บัตรตัดจริง กด **เปลี่ยน** แล้วเลือก "กำหนดเอง"
4. เมื่อเติมเงิน กด **บันทึกการเติม** ใส่จำนวน US$ และเงินบาทที่บัตรตัดจริง (โหมดกำหนดเองจะใช้ตัวเลขนี้คำนวณอัตราให้)
5. ส่วน **สรุปค่าใช้จ่าย AI** แสดงเงินที่เติมรวม ค่าใช้เดือนนี้/เดือนก่อน และย้อนหลัง 6 เดือน

ระหว่างหยุด ระบบไม่เรียก MiniMax, ตอบเฉพาะถาม-ตอบที่หัวข้อตรงกับคำถาม, ขออภัยครั้งเดียวต่อ 30 นาทีต่อแชตแล้วเรียกเจ้าหน้าที่, แจ้งผู้ดูแลทางอีเมลและ LINE

| สาเหตุ | รหัส MiniMax | ระบบทำอะไร |
|---|---|---|
| เครดิตหมด | 1008, 2067, HTTP 402 | หยุด ลองใหม่ทุก 10 นาที |
| โควตาแพ็กเกจหมด | 2056, 2062 | หยุด ลองใหม่ทุก 10 นาที |
| key / model ใช้ไม่ได้ | 1004, 2049, 2057 / 2022, 2069 | หยุด เปลี่ยนค่าแล้วลองทันที |
| ขัดข้องชั่วคราว | 5xx, 1002, เครือข่าย | ครบ 5 ครั้งติดกันจึงพัก 2 นาที |

MiniMax ไม่มี API ดูยอดแบบเติมเงินในเอกสาร ยอดในระบบเป็น**ค่าประมาณ**จาก token จริง × ราคา ไม่รวมการใช้ key เดียวกันจากระบบอื่น ควรบันทึกยอดจริงเดือนละครั้ง

## AI ตอบถูกต้องได้อย่างไร
- ใช้เฉพาะรายการที่ "เผยแพร่" + ตารางอบรม/ที่นั่ง/ช่องทางติดต่อ/วิธีชำระเงินจากฐานข้อมูลสด
- ไม่พบแหล่ง, AI ไม่อ้างอิง, อ้างแหล่งที่ไม่มี, มีตัวเลขที่ไม่อยู่ในแหล่ง หรือคำตอบถูกตัด → **ไม่ตอบ** แล้วแจ้งช่องทางเจ้าหน้าที่
- ถามสถานะส่วนตัว → ให้ไปหน้าติดตามหลังยืนยันตัวตน ไม่ส่งให้ AI
- ตัดเลขบัตร เบอร์ อีเมล เลขที่ใบสมัคร ออกก่อนส่งให้ MiniMax (ชื่อบุคคลที่ผู้ใช้พิมพ์เองยังตัดไม่ได้)
- AI ไม่มีเครื่องมือแก้ข้อมูลหรืออนุมัติใดๆ

ข้อจำกัด: การกรองลดความผิดพลาดแต่ไม่รับประกัน 100% ควรทดสอบคำถามจริงก่อนเปิดใช้ · PDF สแกนอ่านไม่ได้ · PDF ไทยบางไฟล์สระเพี้ยน ต้องตรวจก่อนเผยแพร่
**การตอบในแชต LINE** ใช้ `aiService.answer()` ตัวเดียวกัน เปิด/ปิดที่ Admin > แชต ([รายละเอียด](chat.md))
