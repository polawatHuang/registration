# คู่มือผู้ใช้

## ผู้สมัคร
1. **สมัคร:** หน้าแรก กรอก 2 หน้า แนบเอกสาร (JPG/PNG/PDF) ปิดทับศาสนาและหมู่โลหิตบนภาพบัตร กดส่ง แล้วเก็บเลขที่ใบสมัคร
2. **ติดตาม:** เมนู "ติดตามสถานะ" เข้าด้วย LINE หรือใช้เลขที่ใบสมัคร + เลขบัตร + มือถือ ถ้าเอกสารไม่ผ่านจะมีปุ่ม "ส่งใหม่"
3. **เชื่อม LINE:** เพิ่มเพื่อน LINE OA → เมนู → เข้าสู่ระบบ ใบที่สมัครไว้ก่อนให้เพิ่มด้วยเลขที่ใบสมัคร
4. **วันอบรม:** พื้นที่ของฉัน → QR → "ขยายเต็มจอ" ให้เจ้าหน้าที่สแกนตอนเข้า (และตอนออก ถ้ารุ่นนั้นกำหนด) ถ้า QR หลุดให้กด "ออก QR ใหม่" ใบเดิมใช้ไม่ได้ทันที
5. **ใบประกาศ:** พื้นที่ของฉัน → ใบประกาศ → ดูหรือดาวน์โหลด PDF
6. **สิทธิของคุณ:** ขอลบข้อมูล ถอนความยินยอม หรือยกเลิกเชื่อม LINE ได้ที่หน้าติดตามสถานะ

## เจ้าหน้าที่เช็กชื่อ
1. เปิด Admin > เช็กชื่อ บนมือถือ เลือกรุ่น อนุญาตกล้อง
2. เลือก **เช็กอิน** หรือ **เช็กเอาต์** เล็ง QR ดูสีผล: เขียว = สำเร็จ, เหลือง = เคยบันทึกแล้ว, แดง = ห้ามเข้า
3. **เทียบภาพหน้าตรงกับตัวบุคคลทุกครั้ง** ชื่อถูกแต่คนไม่ตรงให้แจ้งหัวหน้า
4. QR มีปัญหา: แท็บ "รายชื่อและผล" ค้นชื่อ → เช็กอินเอง ใส่เหตุผลหลังตรวจบัตรตัวจริง
5. กล้องเปิดไม่ได้: กด "ถ่ายรูป QR"

## เจ้าหน้าที่ฝึกอบรม
| งาน | วิธี |
|---|---|
| ตรวจเอกสาร | ผู้สมัคร → เปิดใบ → ผ่าน/ไม่ผ่านพร้อมเหตุผล → เปลี่ยนสถานะ |
| ตั้งเกณฑ์ผ่าน | ตัวเลือกฟอร์ม > รุ่น > จำนวนวัน ชั่วโมงขั้นต่ำ ต้องเช็กเอาต์ (ผู้มีสิทธิ์จัดการหลักสูตร) |
| ประกาศผล | เช็กชื่อ > รายชื่อและผล > "ประกาศผ่านผู้ที่ครบเกณฑ์" หรือเลือกรายคน (ไม่ครบเกณฑ์ต้องระบุเหตุผล) |
| แก้บันทึกผิด | เปิดชื่อ → ลบเวลาออก/ลบทั้งวัน (ทำได้ก่อนประกาศผลเท่านั้น) |
| ออกใบประกาศ | ใบประกาศ > ออกใบ > เลือกคน > ออก ผู้รับได้แจ้งเตือนอัตโนมัติ |
| ออกแบบใบ | ใบประกาศ > แบบใบประกาศ ใส่ภาพพื้นหลัง A4 แนวนอน ลากข้อความ กด "ดู PDF" ก่อนบันทึก |
| ชื่อผิด | เพิกถอนใบเดิม → ออกใบ > เลือกคนนั้นคนเดียว → "แก้ชื่อแล้วออก" |
| ตอบแชต | แชต > เลือกลูกค้า ปิด AI รายแชตได้ |

## ผู้ดูแลระบบ
- **LINE OA:** ดูความพร้อม เผยแพร่ Rich Menu แก้ข้อความต้อนรับ ดูผู้ใช้ที่เชื่อมแล้ว
- **แจ้งเตือน:** เปิดระบบ แก้ข้อความ ตั้งเวลาเตือน ส่งกลุ่ม เปิดอีเมลแทนสำหรับผู้ไม่เชื่อม LINE
- **คลัง AI:** เพิ่มความรู้ ดูรายงานคำถามที่ตอบไม่ได้แล้วกด "เพิ่มคำตอบ" ตั้งเพดาน token และใส่ราคาตามบัญชี MiniMax เพื่อดูค่าใช้จ่ายโดยประมาณ
- **ตัวเลือกฟอร์ม:** หลักสูตร มหาวิทยาลัย รุ่น ระยะเวลาเปิดร้าน
- **ลบข้อมูล:** พิจารณาคำขอภายใน 90 วัน ลบข้อมูลครบกำหนด
- **ทุกวัน:** ตรวจ Dashboard (แจ้งเตือนล้มเหลว แชตค้าง) และ `db:backup` **ทุกไตรมาส:** ซ้อมกู้คืน
