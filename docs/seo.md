# SEO หน้าแรก

ทำแล้ว: title/description, canonical, Open Graph + Twitter (ภาพ 1200×630 `assets/images/og-cover.jpg`), ข้อมูลโครงสร้าง (Organization, WebSite, Course, FAQ และ EducationEvent จากรุ่นที่เปิดรับจริง), `sitemap.xml`, `robots.txt`, manifest, หัวข้อ h1–h3, เนื้อหาขั้นตอนและคำถามที่พบบ่อย หน้าส่วนตัวและหลังบ้านไม่ถูกเก็บดัชนี

**ไม่มีใครรับประกันอันดับ 1 ใน Google ได้** สิ่งที่เจ้าของเว็บต้องทำต่อ
1. Google Search Console > เพิ่ม `register.cipacmeeting.com` แบบ Domain (ยืนยันด้วย DNS TXT) > ส่ง `https://register.cipacmeeting.com/sitemap.xml` > ตรวจ URL หน้าแรก > ขอให้จัดทำดัชนี
2. ตรวจที่ Rich Results Test และ Facebook Sharing Debugger (กด Scrape Again) และ LINE Page Poker เพื่อล้างภาพเก่า
3. ให้เว็บมหาวิทยาลัยและหน่วยงานที่เกี่ยวข้องลิงก์มาที่หน้านี้ (สำคัญที่สุดต่ออันดับ)
4. เปิดรุ่นอบรมจริงและกรอกข้อมูลติดต่อ หน้าเว็บที่ไม่มีรุ่นเปิดรับมีเนื้อหาน้อย
5. เปลี่ยนโดเมน: แก้ `https://register.cipacmeeting.com` ใน index.html, privacy.html, policy.html, robots.txt, sitemap.xml
