# แจ้งเตือนผ่าน LINE

| เหตุการณ์ | ส่งเมื่อ |
|---|---|
| สมัครสำเร็จ / ได้รับเอกสารใหม่ | ทันที |
| เอกสารไม่ครบ / ผ่าน / อนุมัติ / ไม่ผ่าน / ยกเลิก | เมื่อเจ้าหน้าที่เปลี่ยนสถานะ |
| เตือนก่อนวันอบรม | ตามจำนวนวันที่ตั้ง เวลา 09:00 น. เฉพาะผู้ได้รับอนุมัติ |
| เตือนก่อนเริ่ม | ตามจำนวนชั่วโมงที่ตั้ง |
| แบบประเมิน | หลังอบรม เฉพาะผู้ที่บันทึกว่าเข้าอบรม และตั้งลิงก์แล้ว |
| ผ่านการอบรม / ออกใบประกาศ | ข้อความพร้อมแล้ว จะเริ่มส่งเมื่อมีระบบเช็กชื่อและใบประกาศ |

## หลักการ
- **เริ่มต้นปิดอยู่** เปิดที่ Admin > แจ้งเตือน เหตุการณ์ก่อนเปิดหรือระหว่างปิดไม่ถูกส่งย้อนหลัง
- ส่งเฉพาะ LINE ที่ผูกกับใบสมัคร หรือผูกกับบุคคลหลังเอกสารผ่าน ตรวจซ้ำตอนส่งว่ายังเชื่อมอยู่ ไม่บล็อก และเพิ่มเพื่อนแล้ว
- ถ้าสถานะเปลี่ยนไปก่อนส่ง หรือเลื่อนรุ่น ข้อความเก่าถูกยกเลิก
- ข้อความสร้างตอนส่งจริง คิวไม่เก็บชื่อหรือเนื้อหา ไม่มีเลขบัตรหรือเบอร์ในข้อความ
- ล้มเหลวชั่วคราวลองใหม่ 4 ครั้ง (1, 5, 30, 120 นาที) ด้วย retry key เดิม ผู้รับได้ข้อความเดียว พ้น 48 ชั่วโมงยกเลิก
- โควตาหมดหรือ token ผิด หยุดทั้งชุดโดยไม่เสียจำนวนครั้ง

## แจ้งเจ้าหน้าที่
1. แท็บ "แจ้งเจ้าหน้าที่" กดเชื่อม LINE แล้วส่งรหัสให้ LINE OA
2. เลือกว่าใครได้รับเรื่องอะไร (เลือกได้เฉพาะที่มีสิทธิ์)

ข้อความถึงเจ้าหน้าที่**ใช้โควตา** จึงรวมเหตุการณ์ใกล้กันเป็นข้อความเดียว (ขอคุยกับเจ้าหน้าที่ 1 นาที อื่นๆ 5 นาที)

## ส่งกลุ่ม
เลือกรุ่น มหาวิทยาลัย และสถานะ ระบบนับผู้รับจริงและตรวจโควตาก่อน ถ้าจำนวนเปลี่ยนต้องยืนยันใหม่ คนที่มีหลายใบได้ครั้งเดียว ผู้รับพิมพ์ "หยุดรับข่าว" เพื่อคัดค้านได้ (ยังได้รับแจ้งสถานะ)

## ข้อจำกัด
- ผู้สมัครที่ไม่ได้เชื่อม LINE ไม่ได้รับแจ้งเตือน (มีเพียงอีเมลยืนยันการสมัคร)
- เตือนตามเวลาต้องมี Plesk Scheduled Task ทุก 5 นาที
- "ส่งแล้ว" หมายถึง LINE รับข้อความแล้ว ไม่ใช่ผู้รับอ่านแล้ว
