# การลบข้อมูล (PDPA)

อ้างอิง: พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 มาตรา 33, 37(3) และประกาศ สคส. เรื่องหลักเกณฑ์ในการลบหรือทำลายฯ พ.ศ. 2567 (ราชกิจจานุเบกษา 13 ส.ค. 2567)

| กลุ่ม | เริ่มนับ | สิ่งที่ลบ |
|---|---|---|
| ถอนความยินยอม | ทันที | ภาพบัตรที่ส่งก่อนถอน (ใบที่ยังตรวจอยู่จะขอภาพใหม่) |
| เอกสารครบกำหนด | วันอบรมเสร็จ | ไฟล์แนบทั้งหมด |
| ใบไม่ผ่าน/ยกเลิก | วันที่ไม่ผ่าน/ยกเลิก | ใบสมัคร ไฟล์ และบุคคลที่ไม่มีใบอื่น |
| ใบสมัครครบกำหนด | วันอบรมเสร็จ | เหมือนข้างบน |
| บัญชี LINE ที่ไม่ใช้ | ใช้งานล่าสุด | ชื่อ รูป รหัส LINE |
| บันทึกการใช้งาน | วันที่บันทึก | Audit Log |

- ระยะเวลาตั้งที่ Admin > ตั้งค่า > กฎหมาย/PDPA เป็นตัวเลขชุดเดียวกับที่แสดงใน privacy.html
- **ไม่มีการลบข้อมูลใหม่อัตโนมัติ** Super Admin ตรวจรายการ พิมพ์ "ลบถาวร" และยืนยันรหัสผ่าน ระบบตรวจเงื่อนไขซ้ำก่อนลบแต่ละรายการ
- เป็นการลบแถวและไฟล์จริง ไม่ใช่การทำเป็นนิรนาม เหลือเพียงหลักฐานที่ไม่มีชื่อหรือเลขใบสมัคร
- ใบที่มีข้อพิพาทหรือกฎหมายให้เก็บ กด "ระงับการลบ" ในหน้าใบสมัคร
- คำขอลบจากผู้สมัครมีกำหนด 90 วัน ระบบเตือนเมื่อเหลือ 14 วัน และอีเมลแจ้งผล ถ้าส่งไม่สำเร็จให้กด "ส่งอีกครั้ง" หรือ "แจ้งทางอื่นแล้ว"
- คำขอลบที่อนุมัติขณะยังไม่อบรม ผู้สมัครเสียที่นั่งและที่นั่งว่างคืน

## ข้อมูลสำรอง
`STORAGE_PATH/purge-ledger.jsonl` คือบัญชีการลบ ให้สำรอง**แยกจากชุดสำรองปกติ**และเก็บฉบับล่าสุดเสมอ ถ้ากู้ทั้ง DB และ storage ย้อนหลัง ให้วางบัญชีฉบับล่าสุดกลับก่อน แล้วรันก่อนเปิดเว็บ:
```bash
npm run retention:reapply
```
ต้องใช้ `DATA_HASH_KEY` เดิม มิฉะนั้นจับคู่รายการไม่ได้ และควรกำหนดรอบหมุนเวียนข้อมูลสำรองให้สั้น

## ข้อจำกัด
- ไฟล์ Excel ที่ส่งออก อีเมลที่ส่งไปแล้ว และสำเนานอกระบบ ต้องลบเองตามระเบียบหน่วยงาน
- การลบไฟล์บน SSD/hosting เป็นการลบระดับระบบไฟล์ เนื้อไฟล์ถูกเข้ารหัสไว้อยู่แล้ว
- แอปเขียน log ลง stdout (ไม่มีเนื้อหาใบสมัคร) และ nginx มี access log ของ Plesk ต้องตั้งการหมุนเวียนให้ตรงกับประกาศ
