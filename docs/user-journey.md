# User journey: "จากเมล็ดสู่ใบประกาศ"

เรื่องเดียวกันทั้งเว็บและ LINE OA สีเขียว/ม่วง/ส้มชุดเดียวกัน ทุกสถานะต้องตอบได้ว่า **"ตอนนี้ต้องทำอะไร"**

| ช่วง | เว็บ (ทำแล้ว) | LINE OA (เกณฑ์ส่งมอบรอบ 2–5) |
|---|---|---|
| พบเจอ | ทุ่งนาเคลื่อนไหว ปุ่ม LINE เด่น | Welcome Flex ต้นกล้า (ทำแล้ว) + Rich Menu 6 ปุ่มธีมเดียวกัน |
| สมัคร | ต้นกล้าโตตาม % ที่กรอก ช่องเลขบัตรเด้งเขียว สแกนเอกสาร | เปิดฟอร์มเดิมใน LIFF รู้จักผู้ใช้จาก LINE |
| สำเร็จ | ใบไม้ฉลอง บัตรดิจิทัล 3 มิติ บันทึกเป็นรูป + อีเมล | Flex "เมล็ดลงดินแล้ว" พร้อมเลขที่และปุ่มติดตาม |
| รอตรวจ | เถาวัลย์ 9 ขั้นและการ์ด "ก้าวถัดไป" | ทำแล้ว: Flex แถบ 9 ช่อง ส่งเมื่อสถานะเปลี่ยน |
| ต้องแก้ | บอกเหตุผลรายเอกสาร ส่งใหม่จุดเดียว | ทำแล้ว: Flex สีส้ม ปุ่มเดียวเปิดหน้าส่งใหม่ |
| อนุมัติ | ฉลองเมื่อกลับมา "ต้นกล้าโตขึ้นอีกขั้น" + นับถอยหลัง | Flex อนุมัติ + เพิ่มลงปฏิทิน/แผนที่ |
| วันอบรม | — (รอบ 4) | QR เต็มจอสว่างอัตโนมัติ เช็กอินแล้วเด้งต้อนรับทันที |
| จบ | — (รอบ 4) | ดอกไม้บาน ใบประกาศ PDF และภาพแชร์ |
| สงสัย | — | ทำแล้ว: AI ตอบจากคลังความรู้พร้อมปุ่มลัด ไม่รู้แล้วส่งต่อเจ้าหน้าที่ในแชตเดิม |

เกณฑ์: แตะไม่เกิน 2 ครั้งถึงข้อมูลสำคัญ, เป้าแตะสูง ≥ 44px สำหรับเมนูหลัก, ไม่ล้นที่ 320px, ปิดเอฟเฟกต์เมื่อผู้ใช้ลดการเคลื่อนไหว, ไม่มีทางตัน
